# 拾忆 Recall · 基于间隔重复的错题复习系统

> 用 SM-2 间隔重复算法给每道错题排复习期，把「记了不看、看了就忘」变成一条可执行的日程。

**在线地址**：`https://<你的 GitHub 用户名>.github.io/recall/` （开启 Pages 后自动生效）

---

## 为什么做这个

错题本的通病不是"记不下来"，而是**记下来之后没有再打开的理由**。手抄一遍当时懂了，
一周后再遇到照样错。艾宾浩斯遗忘曲线给出的答案是：在快要忘掉的那一刻再复习一次，
记忆衰减就被重新拉起——**间隔重复（Spaced Repetition）**。

本系统把这件事自动化：你只需要诚实回答"想起来有多难"，剩下的排期交给算法。

## 核心算法

SM-2 的简化实现，每张卡片维护四个状态量：

| 状态量 | 含义 | 更新规则 |
|---|---|---|
| `ef` | 难度因子 Easiness Factor，∈ [1.3, 2.8] | 记得 +0.08 / 模糊 −0.05 / 忘了 −0.20 |
| `reps` | 连续答对次数 | 忘了则归零，否则 +1 |
| `interval` | 下次复习间隔（天），上限 365 | 第 1 次 1 天、第 2 次 3 天，之后 `interval × ef` |
| `due` | 下次到期日 | `今天 + interval` |

三档评分对应：

- **忘了** → `ef − 0.20`，`reps` 归零，`interval` 重置为 1 天（明天再来）
- **模糊** → `ef − 0.05`，间隔 ×1.2（温和拉长）
- **记得** → `ef + 0.08`，间隔 × ef（越熟练推得越远）

掌握度用于可视化展示，**不参与调度决策**：

```
mastery = 100 × (1 − e^(−(interval/30 + reps/4)))
```

## 功能

- **今日复习**：卡片翻转 → 三档评分 → 实时更新 EF / 间隔 / 到期日
- **错题库**：增删改查，按学科与掌握度筛选
- **数据统计**：掌握度分布环形图、8×7 复习热力图、连续打卡天数、学科横向对比
- **迭代记录**：全部评分历史可回溯
- **数据可携**：JSON 导出 / 导入，localStorage 持久化
- **响应式**：桌面侧边栏，≤760px 自动切底部导航栏

## 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 框架 | 原生 HTML / CSS / JS，零第三方依赖 | 无构建、无 CDN、离线可用 |
| 存储 | localStorage（键 `recall.store.v3`） | 单机场景够用，省掉后端与账号体系 |
| 部署 | GitHub Pages + Actions | 免费、稳定、可复现 |

## 本地运行

```bash
# 方式一：直接双击
open site/index.html

# 方式二：起个本地服务
python -m http.server 8000 --directory site
```

单文件版本已把 CSS 与 JS 全部内联，**断网也能用**。
